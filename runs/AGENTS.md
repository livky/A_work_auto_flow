# 全局 Run 规则

Run 是独立分析/仿真/验证证据，可关联零个或多个核心算法、研究、数据和上游 Run，不要求创建项目。

使用根 new-run --title 创建，--module 和 --research 可重复。执行状态、复核状态、输入版本、关键产物与适用域分开记录。复核和撤回遵循 context/MEMORY.md，原结果和复核历史保留。

只将实际消费的上游结果登记为 parent_run_ids。小型关键结果文本与 run.json 同目录，方便关联检索；大数据保留受控引用。

本目录材料进入问答上下文时遵循根分阶段策略；算法必读不表示算法必然正确，Run 摘录不表示完整证据已读。新增/修改材料的整理批次结束后更新 index-knowledge。
