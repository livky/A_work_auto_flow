# 无归属 Run 与通用运行规则

Run 是独立分析/仿真/验证证据，可关联零个或多个核心算法、研究、数据和上游 Run，不要求创建项目。

无业务归属的轻量任务使用 `new-run --title` 落根 runs/；有归属用 `new-run --owner 对象ID --title` 落对象内 runs/。唯一研究关联可自动作为归属，多研究时必须明确 owner；关联仍可多值，Run不复制。Project用于大型或系统级工作，不为一次计算强建项目。旧根目录和旧项目Run继续可读，不为换布局改写历史证据。

L0完整输入/输出用于追溯；本次重要计算另存可读 L1 detail，引用该 Run，包含关键参数、公式、推导说明、结果和限制。详细说明是文档，不计作第二次实验。执行状态、复核状态、输入版本、关键产物与适用域分开记录，复核和撤回遵循 context/MEMORY.md。

只将实际消费的上游结果登记为 parent_run_ids。小型关键结果文本可与 run.json 同目录，通过输入/产物登记与固定引用追溯；原始结果不会仅因在目录中就进入常规知识排名。大数据保留受控引用，完整过程另由 L1 技术单元解释。

本目录材料进入问答上下文时遵循根分阶段策略；算法必读不表示算法必然正确，Run 摘录不表示完整证据已读。文件索引按需执行 index-knowledge；规范记忆提交检查索引回执，待补偿时执行 memory reconcile，不重复创建实验或记忆记录。
