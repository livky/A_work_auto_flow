# 无归属运行与历史兼容入口

无业务归属的轻量任务用 `new-run --title "分析目的"` 保存在根 `runs/`。有归属时使用 `new-run --owner 对象ID --title "分析目的"`，目录型对象保存到自己的 `runs/`，平面材料和工具使用专用运行容器。唯一研究、项目或唯一核心算法关联也可推定归属；多个研究关联必须显式指定 owner。一个 Run 可以被多个对象引用，但只保留一个物理归属，不要求为了运行建项目。

旧根 Run 和 `projects/<slug>/analysis/runs` 继续按稳定 RUN-ID 发现、检索和复核，不为整理布局搬移或重写原始证据。2026-09-09 main 根目录已移除历史实例，只保留规则与运行说明；浮点研究的配套历史在该研究内保留，仅在隔离例子中恢复旧布局。完整 checkout 可从浮点研究 README 查看，公共发行不包含该实例。

执行和已有材料登记见 [Run 捕获手册](../docs/RUN_CAPTURE.md)，对象目录、L1 技术说明与固定引用见 [分层记录标准](../docs/RESEARCH_RECORDING.md)。L0 原始结果用于追溯，常规知识检索使用 L1 及以上；检索到说明不表示已经读取完整输入和日志。
