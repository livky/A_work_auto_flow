# RUN-20260907T023756Z-035991E67BBA：证据查看界面与只读监测实现验证

## 问题与成功标准

- 问题：能否用轻量本地界面解释证据保存/复核/失效和报告影响，并只读观察变化，不因重复而提升可信状态？
- 成功标准：现有业务记录不被查看/监测修改；来源与复核可追溯；首次只建基线；重复轮询不重复记事件；变化形成候选，可信状态保持原值。

## 输入与范围

- 输入：[实施计划](../../docs/design/evidence-view-monitor-plan.md)、前批 evidence.py 与当前源码；指纹见 inputs.json。
- 数据：合成隔离工作区测试，以及本工作区已有的框架研究/实现 Run；没有公司材料。
- 范围：本地只读界面、单次可调度监测、技能入口、使用及升级文档；没有安装定时任务。

## 方法与参数

界面复用 EvidenceGraph，支持逐条结论与旧 Run，展示记录理由、证据/产物当前版本、复核历史、风险观察时间和下游报告。HTTP 仅监听回环地址，有随机访问路径与固定只读路由，不提供任意文件服务。

监测复用获准来源及已登记引用，保存单个原子状态文件。支持材料变化、实验终态、复核和依赖风险事件，以及完全相同内容的比较候选；不调用模型或索引，不执行合并、删除、实验或复核晋升。见 [使用手册](../../docs/EVIDENCE_VIEW_MONITOR.md)。

## 结论、限制与下一步

- 结论：轻量界面与可重复的只读监测已实现、验证并建立本机基线；新增技能 evidence-inspection 已安装。
- 限制：定时频率尚待用户选择，未创建自动化；候选不会自动处理或提升可信状态。没有真实领域验收、大规模历史性能或跨物理电脑测试。原有向量/OCR 缺失仍存在。
- 下一步：按用户选择启用定时调用；材料接入后补充 record_reason、逐条结论与报告依赖，并按实际证据复核。
