步骤与验收：

- [x] 核查入口与误分类原因：导入允许按脚本用途建模块，代码默认归 core-code。

新行为覆盖：缺文档引用时创建前拒绝、兼容命令同样要求来源、中文/引号/反斜线路径正确保存、只登记不标已读、dry-run 不落盘、校验器发现缺来源、普通脚本与辅助说明不进入核心证据默认类别。

验证限制：文档引用不证明原件已读或公司认可；业务准入需依据实际材料判断，单元测试只验证框架行为。当前没有真实公司算法条目。
