| 文件更新与旧索引可能脱节 | SHA-256 增量同步、变化/删除停用旧内容、装载再检查；编码库和模型身份隔离集合 |

| 长文多片段扭曲来源排序、泛目录误扩展 | 向量按文件去重后的排名融合；只有实际含 Run 元数据的目录才做 Run 同目录扩展 |
