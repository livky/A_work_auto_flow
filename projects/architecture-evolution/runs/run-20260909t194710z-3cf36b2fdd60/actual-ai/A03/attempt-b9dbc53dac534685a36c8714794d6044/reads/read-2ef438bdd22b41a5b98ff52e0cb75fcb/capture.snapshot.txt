表示查询运行实现：契约、范围和累计资源\n\n本轮在既有版本记忆之上增加材料查询应用。类型定义说明如何组织材料；候选指向已固定的规范记录；组包按用户选择组合正文，不产生第二套规范正文。原始、全文、章节、单元概览、专题和领域六种定义由同一注册表提供。字段缺失返回真实可用性；只有请求允许时才按注册的回退顺序换用表示。\n\n## 范围与固定身份\n\n设可信授权为 $A$，请求硬上限为 $C$，当前选择为 $S$，显式排除为 $E$。可输出集合为：\n\n$$\nO=(A\\cap C\\cap S)\\setminus E.\n$$\n\n其中空集合表示无结果，`null` 表示该维度不限。必需来源可以位于当前选择以外，但必须位于 $A\\cap C$ 且未被排除；正文读取之前核验这一边界。进入材料包时仍检查当前输出范围。这样可以识别“来源存在但不可输出”的缺口，同时避免由派生材料越界读取原件。\n\n记录引用包含修订号和 SHA256；历史读取保持旧版字节，当前查询另行核对真实 HEAD。显式 `block:` 定位沿候选、选择和组包保留；找不到相关块时报告缺失，不能把第一块当作回答。完整块的 `requires_block_ids` 决定所需定义，公式和定义不从中间截断。读取依据记录固定引用、owner HEAD、索引水位、观察时间与依据身份；跨 owner 是乐观观察，不能冒充全局事务快照。\n\n## 资源与状态\n\n对资源种类 $r$，各阶段共享总额度 $B_r$。第 $i$ 阶段消耗为 $c_{i,r}$，下一次操作之前要求：\n\n$$\n\\sum_i c_{i,r}+c_{\\mathrm{next},r}\\leq B_r.\n$$\n\n读字节以实际 UTF-8/文件字节计；输出以字符计；候选、节点、边、跳数、模型调用及输入输出 token 分开计量。活动墙钟按阶段并集累计，用户等待不扣活动时间；查询 TTL 独立。保留已完成消耗，取消或预算耗尽不能清零重试。提供器预留和结算使用同一账本；真实超额会阻止新工作，不能把消耗截断成上限制造达标。\n\n查询后显式选择候选再组包。正式模式按 claim 检查适用域和当前依据，一篇记录仅一个 claim 获准时不会带入其余结论；旧复核记录仍可读取，但不因此继续有效。材料包显示来源、补充定义和缺口。结构化 Issue `FINAL_VALIDATION.md`。本单元是软件实现说明，不证明检索质量、模型有效性或未执行策略。\n\n\n# 表示查询首期软件验证固定记录\n\nRun：`RUN-20260909T194710Z-3CF36B2FDD60`，本机 Windows 11 x64、Python 3.12.10、Node 22.11.0。验证时源码含既有未提交修改，未创建新 Git
