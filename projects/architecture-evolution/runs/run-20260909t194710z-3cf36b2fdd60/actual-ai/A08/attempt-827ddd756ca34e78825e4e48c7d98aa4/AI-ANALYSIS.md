## 共同部分与决定性差异

两边都有观测结果、调整动作和限幅条件，可以把“先区分未受限与受限区间，再检查边界行为”作为一个待采用的分析方法。相似只到这个局部结构。

| 比较维度 | 水箱负反馈 | API 退避重试 | 对类比的影响 |
|---|---|---|---|
| 状态与观测 | 连续液位 $h$，目标 $h_r$，有量纲误差 $e=h_r-h$ | 失败计数 $k$ 与三类响应，无负载或目标误差测量 | 不能把 $k$ 当成液位误差 |
| 动作 | 入流命令 $q_c=ch_r+Ke$，实际流量受泵限制 | 失败后安排下一次等待 $d_k$，成功或终止条件结束流程 | 等待策略未定义对服务端状态的作用方程 |
| 时间机制 | 连续一阶动力学，守恒方程连接流量与液位 | 离散事件流程，缺少服务端到达率、处理率与响应分布 | 没有可转写的同一状态方程 |
| 指数项 | 未饱和区误差随时间衰减 | 连续失败时等待随序号增大，直到封顶 | 两个“指数”方向、变量和含义均不同 |
| 参数与单位 | $K$ 为 $\mathrm{m^2/s}$，$A$ 为 $\mathrm{m^2}$ | $r=2$ 无量纲，$b$ 与 $d_{max}$ 为秒 | 不能令 $K=r$ 或迁移水箱数值增益 |
| 上限 | $q_{max}$ 是实际执行器容量 | $d_{max}$ 是策略等待上限 | 限等待不等于限制并发、队列或业务副作用 |

决定性差异是：水箱前提给出动作如何影响状态的守恒模型，API 前提没有服务端状态转移或负载反馈模型。因此，水箱的闭环误差解不能证明 API 稳定、最优吞吐或最终成功。

## 有条件参考

可以参考水箱材料的**分段检查方法**：对 API 先把 $br^k<d_{max}$ 与已封顶两种等待情况分开，再逐个检查成功、可重试失败、不可重试失败与次数终止条件。这个建议只在 API 已明确幂等或去重语义、可重试错误分类、超时与总耗时边界后适用。它不移植水箱公式、不推荐数值参数，也不声称这种策略已经改善性能。

## 不可推广的负例

不接受“水箱增加比例增益能缩短线性段时间常数，所以增大 API 倍率也必然更快、更稳定”的推论。水箱时间常数

$$
\tau=\frac{A}{c+K}
$$

只适用于给定无延迟且未饱和的连续模型；$A$ 为面积，$c,K$ 为流量对液位的系数。API 的

$$
d_k=\min(d_{max},br^k)
$$

定义的是第 $k$ 次连续失败后的等待；$b,d_k,d_{max}$ 为秒，$r$ 为无量纲倍率。即使未触顶，在 $k>0$ 时增大 $r$ 也会延长这次等待；最终成功率和总完成时间还依赖材料没有给出的响应过程。可以拒绝上述跨机制保证，但不能进一步宣称该 API 策略在所有系统都无效。
