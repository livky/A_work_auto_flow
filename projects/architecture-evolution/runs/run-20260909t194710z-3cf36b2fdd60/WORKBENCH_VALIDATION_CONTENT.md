## 已发现的真实问题

实际浏览器发现维护审查虽有有效内容，但返回 partial 时界面仍按失败阻断。现根据状态和错误码判断可操作结果，并保留未完成审查及相同失败请求供重试。另修复了过期复核被当作当前有效、显式技术块定位丢失、全文漏结构字段、单元概览遗漏禁用条件及必要来源越过 owner 硬上限等问题。回归测试保留这些具体反例，不以删除失败样本消除故障。

验证分为软件功能测试、实际 AI 使用和人工验收。前端类型检查、组件、真实 Edge 与布局截图是不同证据；实际 AI 必须读材料、提交请求并回读后逐项自查。固定 fixture 的历史指纹差异保留为已知失败；没有把它改成当前通过。具体测试数量和最终失败状态只引用同一 Run 的 `FINAL_VALIDATION.md`，不从过程中的部分通过推断整体通过。

## 分发和维护方式

前端源代码及锁文件供开发，预构建工作台资源及指纹随新版源码分发；使用端无需 Node。Python 运行环境与模型仍通过独立配套依赖 ZIP 和 SHA256 文件分发，本次没有更换 Python 锁或标准模型。Windows 升级从独立新版目录执行 `setup.cmd --target "旧工作区路径" --register --open`，继续使用原工作区；新旧目录不能互相嵌套。

真实升级测试使用含多层业务目录、中文/空格路径、空目录、工具、用户 Skill、缓存和规范维护计划的共享合成旧工作区，核对预览、升级、重复升级及恢复的受保护文件哈希与目录。当前来源登记包含项目工作数据，不能直接把这份完整工作区当作公共发行包。第二台物理机、人工业务验收及万条规模实验分别保留未执行，不由本机隔离测试替代。

日常入口和概念见根 README 与材料查询手册。技术单元、事件、经验、地图和完整/精简两份文稿由公开版本记忆入口维护；Run 保存代码/配置指纹、原始回执和实际自查。历史设计保留其原来时点，当前实现另存新章节，从而区分“曾计划”“已实现”和“已验证”。
