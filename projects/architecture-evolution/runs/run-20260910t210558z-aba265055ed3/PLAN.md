# 材料查询七项优化

## 用户目标与验收

1. 实际范围与材料结构按标准 Owner 类型单选/多选；先分类再定位，附对象名称搜索，保留显式排除与空集合语义。
2. 新增所有来源，涵盖已登记的内容类型；默认仍为概览与经验。
3. 默认活动读取时间预算5分钟；累计计量、取消及其他资源预算仍生效。
4. 默认只查询记录的最新修订；显式允许历史时可查旧结果并标记版本，不自动替换固定引用。
5. 选中命中后返回对应的已有完整文稿，按文稿固定身份去重；展开可返回必要上下文与已启用的关联补充，缺少关联/来源如实报告。
6. 常用操作集中且保持可见，反复检查选择、展开、组包、深化、结果切换与失败状态；真实浏览器验证。
7. 逐项核对工作区 Skill 的适用场景、登记、调用与现行契约，补开发后的闭环要求，移除确认过时入口并保留恢复/处置依据。

## 影响与实现原则

MQ 负责标准类型、版本范围、候选/正文与文稿关联；MEM 不新建第二套状态。历史读取有界、可取消，按当前权限核验。APP 消费统一契约，不用前端隐藏冒充后端筛选。DOC 的已有章节/文稿关系复用。GUIDE 的登记、发现包装、规则、手册和升级清单逐项一致；不删除与本工作区无关的全局插件技能。
