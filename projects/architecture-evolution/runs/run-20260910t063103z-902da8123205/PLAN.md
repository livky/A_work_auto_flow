# 登记覆盖审计与人工验收

目标：核对当前工作区已有业务对象、来源、Run输入/产物、版本记忆、文稿和两条索引；安排工作台及实际AI最终验收。

范围：本工作区八类业务目录、显式来源登记和派生索引；不递归共享盘，不将缓存、历史回执和原始数据全部变成知识候选。

步骤：保存只读基线；对账对象/当前及历史修订/固定来源/文稿/FTS水位；区分合理排除与真实缺口；必要时仅重建派生索引；生成可执行人工检查表及反馈记录入口；登记本轮证据、刷新导航、运行validate。

本轮不修改产品代码。OBJ/MEM/EVD/RET/DOC只读核对；APP/QA核对现行页面与验收目录；GUIDE新增本轮人工操作指南。接口、Skill、预构建资源、模型、依赖和模块职责无需修改；Windows升级测试不因增加审计文档而重跑。人工判断与科学复核保持待审。万条测试、第二台物理机、企业材料接入不在本轮执行范围。

验收需要用户实际操作和评价，准备完成不等于人工通过。任何异常保留原始指纹与历史记录，不能通过重新登记新哈希掩盖变化。
