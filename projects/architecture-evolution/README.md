## 如何维护

开发按 development-checks 在开始及完成后完整重读六份短文档，按影响展开细节。现行架构和功能只在全局入口维护，本 Project 保存任务目标、处理结果和必要历史快照。小任务可直接写计划/摘要，有独立验证产物时再用 Run；不重复创建另一套全局定义。

图的箭头表示“此处变化会要求另一处重新检查”，不等同于全部 Python import，也不代表自动执行或自动验证。通用操作约定见[文档与影响维护](../../docs/DOCUMENTATION_MAINTENANCE.md)。
