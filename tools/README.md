# 分析与自动化工具

新建业务分析工具时，通常直接让助手在这里创建，无需用户先建项目。`automation/` 留给框架自身的索引、创建和复核等功能；项目专用脚本放对应项目的 `analysis/`。当前没有 `new-tool` 命令，助手负责创建文件、补说明和维护注册表；仅把脚本复制进目录不会自动登记。

## 目录

- `scripts/`：轻量 CLI 和一次性脚本晋升后的入口。
- `packages/`：有核心算法边界、测试和版本的可复用包。
- `external/`：公司工具、第三方工具、MCP/连接器和报告平台适配器。
- `registry.json`：派生索引读取的工具注册表。

工具卡至少回答：解决什么问题、何时不该用、输入输出和单位、数据权限、依赖环境、验证命令、已知失效模式、维护者和替代工具。
