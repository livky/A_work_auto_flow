# 公司核心算法：按需核对

核心算法只指公司算法/模块文档定义的关键模型算法；原文“模块”可作为别名，普通工具不因此建MOD。先看目标目录AGENTS，定位公司文档名称/版本/章节，未知不编造。核心算法跨项目共享，使用固定引用，不复制卡片。

核对算法时优先读定义目标、输入输出、公式和适用条件的原文，再根据缺口检查代码、Run与其他材料。保留单位、坐标、时间基准、离散方式及失效范围；软件实现通过不证明模型现实有效。无需每次全读整个算法目录。

默认查找/完整阅读走material-query；已有CTX任务继续用retrieve-context/context-feedback兼容链，保持用户include/full/exclude和原预算，身份不得混用。旧CTX最多两级的限制只作用于该旧入口，不是RS阅读次数策略。命令和缺口语义见[检索手册](../../../../docs/RETRIEVAL.md)。

文档与代码冲突时保留两端版本、实际差异及影响；新分析通过work-loop保存，不反写旧材料。来源变化需下游语义修订时才使用semantic-maintenance。
