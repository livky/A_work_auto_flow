# 正式知识库

## 分类

- `decisions/`：架构、算法、接口、数据格式和工具选型 ADR。
- `incidents/`：数据异常、模型失效、脚本事故、误诊断和显著返工复盘。
- `patterns/`：经多个 Run 验证、可跨项目复用的做法与反例。
- `reviews/`：周期性质量、技术债、文档漂移和工具健康回顾。

## 晋升规则

候选内容只有满足以下条件才成为正式知识：

1. 有来源或可复核 Run。
2. 区分事实、推断和建议。
3. 标注适用域、版本、时间和反例。
4. 有 Owner 和复核状态。
5. 与项目、模块、数据和决策建立链接。

AI 可起草，关键技术结论由人或明确验证流程批准。
