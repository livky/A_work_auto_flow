# 正式知识库

## 分类

- `decisions/`：架构、算法、接口、数据格式和工具选型 ADR。
- `incidents/`：数据异常、模型失效、脚本事故、误诊断和显著返工复盘。
- `patterns/`：经多个 Run 验证、可跨项目复用的做法与反例。
- `reviews/`：周期性质量、技术债、文档漂移和工具健康回顾。

## 晋升规则

候选内容只有满足以下条件才成为正式知识：

1. 有来源或可复核 Run。
2. 区分事实、推断和建议。
3. 标注适用域、版本、时间和反例。
4. 有 Owner 和复核状态。
5. 与适用项目、核心算法、数据和决策建立链接。

AI 可起草，关键技术结论由人或明确验证流程批准。

未复核但值得保存的经验可以先留在所属对象的规范记忆中，标注适用条件、来源和缺口；`discovery=workspace_summary` 只是允许跨对象发现，不等于晋升正式知识。已有平面知识文档可按需采用稳定 Owner，记忆保存到旁置目录，原文不自动复制成新事实。L1 技术单元、L4 地图和独立研究文稿各自维护，详见 [版本记忆指南](../docs/MEMORY_USAGE.md)。
