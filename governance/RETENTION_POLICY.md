# 保留与处置策略

具体年限必须由公司政策、合同、知识产权、法规和存储成本决定；本文件只定义分类方法。

| 类别 | 例子 | 默认策略 |
|---|---|---|
| Scratch/缓存 | 临时下载、缓存、探索图 | 可重算；按保留策略和已有授权清理，当前无自动删除任务 |
| 可重算派生物 | 中间表、批量图、临时模型 | 保留 manifest 与生成方法；数据按成本策略 |
| 受控证据 | 已批准 Run、验证数据、关键日志片段 | 按项目/合规策略长期保留 |
| 正式知识 | ADR、核心算法卡、数据卡、复盘、已验证综合 | 版本化长期保留 |
| 生成报告 | PPT、DOCX、PDF | 保留源、manifest、批准版本和必要附件 |
| 已处置资产 | 删除或不可访问数据 | 保留 tombstone：ID、摘要、来源、处置原因、审批和日期 |

每个项目在关闭前回答：哪些资产唯一、哪些可重算、哪些受法规/合同约束、恢复成本是多少、谁批准处置、如何验证删除或归档完整性。

## 本地检索数据

retrieval/generated 与 services/qdrant/storage 是可重建的派生索引，可含原文/OCR/路径；关闭检索进程后再做文件级备份或恢复。原始资料、业务对象、查询/反馈/CTX 调查链/上下文反馈/策略和版本清单单独保留，不把它们当缓存清理。

运行时、模型和安装包被 Git 忽略，但离线搬迁/恢复需要完整复制 services/qdrant。当前没有自动备份、清理或过期删除。路径变化后刷新索引，历史查询 ID 和反馈保持原记录。
